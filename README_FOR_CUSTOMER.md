# FPSK Guide Bot - Инструкция по установке и запуску

## Что нужно для запуска

1. **Java 17** или выше
2. **Telegram Bot Token** (ключ от BotFather)

## Быстрый запуск

### Вариант 1: Готовый дистрибутив (рекомендуется)

1. Распакуйте архив с проектом
2. Установите Java 17, если не установлена
3. Запустите файл `run_bot.bat`
4. При первом запуске введите токен бота

### Вариант 2: Сборка из исходников

1. Установите Maven и Java 17
2. Откройте командную строку в папке проекта
3. Выполните команду:
   ```bash
   mvn clean package
   ```
4. Запустите бота:
   ```bash
   java -jar target/FPSKGuideBot-0.0.1-SNAPSHOT.jar ID_TOKEN=ВАШ_ТОКЕН
   ```

## Как получить токен бота

1. Найдите в Telegram @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

## Смена токена

Токен хранится в файле `bot_token.txt`. Чтобы сменить токен:

1. Удалите файл `bot_token.txt`
2. Снова запустите `run_bot.bat`
3. Введите новый токен

Или отредактируйте файл `bot_token.txt` вручную.

## Структура проекта

- `run_bot.bat` - основной файл запуска
- `bot_token.txt` - файл с токеном (создается автоматически)
- `target/FPSKGuideBot-0.0.1-SNAPSHOT.jar` - скомпилированное приложение
- `src/` - исходный код (если нужно внести изменения)

## Возможные проблемы

**Ошибка: JAR file not found**
- Решение: выполните `mvn clean package` для сборки проекта

**Ошибка: Java не найдена**
- Решение: установите Java 17 с сайта oracle.com

**Бот не отвечает**
- Проверьте правильность токена
- Убедитесь, что бот запущен без ошибок
